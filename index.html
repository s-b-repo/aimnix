CS2 CV Aimbot v3.0

External Computer Vision Aimbot - Linux
This software is for educational and research purposes only. Using this in online games may result in permanent account bans.

Aim Engine

  • YOLOv8 head detection via ONNX Runtime
  • Assist mode (smooth) and Lock mode (snap)
  • Cubic ease-out smoothing curve
  • Dead zone to avoid micro-adjustments
  • Weighted target scoring (distance + confidence)

Stealth System

  • Micro-jitter on aim path (Gaussian noise)
  • Random overshoot and correction
  • Variable aim speed per frame
  • Per-target aim offset randomization
  • Target switch penalty (stickiness)
  • Randomized reaction delays
  • Configurable miss probability
  • Fire rate limiter
  • Random process name masking (27 common names)

Anti-Recoil

  • Automatic downward compensation during fire
  • Ramps up over sustained bursts
  • Gaussian noise on compensation values
  • Configurable strength and timing

Team Detection

  • HSV body-region sampling (not head)
  • Pixel-level red/blue classification
  • Configurable saturation threshold
  • Targets unknown team by default

Performance

  • Center-screen crop for faster inference
  • CUDA GPU acceleration
  • Deadline-based frame timing
  • GStreamer X11/Wayland capture
  • Configurable downscale resolution

Extra Features

  • Bunny hop auto-jump
  • Panic key (F12) - instant kill switch
  • Config hot-reload (F11)
  • Status overlay on secondary monitor
  • Auto train/val dataset splitting

Quick Setup

1Run setup
chmod +x setup.sh && ./setup.sh
2Collect data
python3 collect_data.py --rate 5 --duration 10
3Label data using makesense.ai or CVAT
4Train model
python3 train_model.py --all --epochs 100
5Run
sudo ./cs2-aimbot-enhanced
